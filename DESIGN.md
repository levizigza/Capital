# Capital — DESIGN

**Mode (Harbor plaza):** Experience — the world leads; UI recedes.  
**Mood:** Cozy Seaside money adventure (see `docs/art-direction-bible.md`).  
**Craft north star:** `docs/astro-craft-translation.md`

## Visual hierarchy (Harbor)

1. Fountain + stone plaza (center read)  
2. Ledger Bank (hero silhouette, always labeled)  
3. Money Carpet Gate on the pier axis (exit / travel)  
4. Outfitter + Arcade pavilions (unique meshes)  
5. Notice board + Memory Plinth  
6. Signpost cluster for utilities (never clone shops)

## Anti-references

- Ring of identical pastel shops  
- Permanent stacked Archipelago CTA fighting the Piggy tip  
- Generic cyan painting portals that ignore island culture  
- Prop rings that fill every degree of the seawall  

## Typography / HUD

App UI: glanceable objective strip, one primary action. Prefer diegetic map at Carpet Gate over always-on chrome.

## Motion

Purposeful only: carpet bob, vault dial, fountain shimmer, guide arrow. Respect `prefers-reduced-motion`.
