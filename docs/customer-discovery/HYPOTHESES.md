## Problem hypotheses

| ID | Hypothesis |
|----|------------|
| H-PAIN-01 | Parents feel high **shame/anxiety** about kids’ money habits and lack a non-lecture tool. |
| H-PAIN-02 | Kids’ allowance/apps teach transactions but not **irreversible choice consequences**. |
| H-PAIN-03 | Classroom financial literacy is either worksheet-dull or blocked by privacy/ads. |
| H-PAIN-04 | Adults know they “should budget” but abandon tools that feel like homework. |
| H-PAIN-05 | Share/Plinth moments create social proof parents want to send to grandparents / peers. |
