# Capital replayability — possibility over repetition

**Verdict:** The spine (Cove → Paycheck → Credit Takes, Soft Beats, mastery quizzes, fixed shores) is mostly **repetition** — re-consuming authored content. True **possibility** lives in Harbor/era party boards + Voyager Ledger, but boards were static and several RNG lands paid out without a skillful decision.

Goal: same mechanics, different runs. Randomness should **pressure a choice**, not replace one.

Freeze: Harbor · Cove → Paycheck → Credit. Family Room stays local. No fake multiplayer.

---

## Variation axes

| Axis | Today (before this pass) | Desired |
|------|--------------------------|---------|
| **Player decisions** | Takes mostly scar/stance; deals are real forks | Takes leave ledger residue; lucky/capsule become forks |
| **System interactions** | Ledger ↔ weather; economy phase weakly wired to board | Economy phase **rotates** board space bias |
| **AI behavior** | Always Sally + Hank first | Session rival roster from full captain pool |
| **Economy** | Holdings diverge runs | Keep; banked windfall links luck → Pay Day |
| **Randomness** | Dice / free capsule / auto liability / flat lucky | Dice still rolls; lucky/capsule/liability open decisions |
| **World generation** | Static 16-space patterns | Session seed **rotates** pattern (no new authored maps) |
| **Other players** | Local Family Room share | Soft social object only (freeze) |
| **Strategies** | Seal race, deal timing, capsules | + bank vs spend windfall; capsule pick; liability fork |
| **Starting conditions** | Cast cosmetic; QA seeds | Unchanged — don’t fake “new game+” with more quests |

## Repetition vs possibility

### Authored repetition (keep as myth spine — don’t multiply)
- Dialogue Takes, Soft Beat lines, mastery quiz banks, Money Structure layouts, Ashore coach
- Cold retell / Plinth / share card

### Mechanical possibility (deepen)
- Board session seed → pattern rotation + rival roster
- Macro economy phase biases space kinds (more bills in recession, more deals in boom)
- Windfall: spend all vs bank half for next Pay Day
- Capsule: choose 1 of 2 items
- Liability land: borrow / buyout / walk (informed fork)
- Spender/haste scars write ledger liabilities (runs diverge after the same Take graphs)

---

## Randomness rule

| Bad | Good |
|-----|------|
| Land lucky → +20 automatic | Land lucky → **choose** spend all / bank half |
| Capsule → random item forced | Capsule → **pick** between two draws |
| Liability → silent −$/mo | Liability → **choose** borrow / buyout / walk |
| Dice decides who wins alone | Dice sets position; minigame skill + deals decide seals |
