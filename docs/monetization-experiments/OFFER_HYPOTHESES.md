# Offer hypotheses

All **PRICE** fields are **experimental hypotheses** for learning — not storefront canon. Founder must approve before any Payment Link.  
Promised outcomes must match **shipped** Capital (Harbor → Cove signature loop; no debit rails; no fake multiplayer).

---

## OFFER_FOUNDING_FAMILY — founding-user access

| Field | |
|-------|--|
| **CUSTOMER** | S1 parent/guardian of child ~7–10; co-play willing |
| **PROBLEM** | Hard to teach money choices without lectures or needing a kid debit card |
| **PROMISED OUTCOME** | Child completes one memorable irreversible money choice and family can retell what changed |
| **WHAT THEY RECEIVE** | Founding household license to current Harbor + Cove spine content; founder office hours once; named on early-supporter list (optional opt-in) |
| **TIME TO VALUE** | ≤1 session (~45–60 min) to Take → Harbor felt |
| **PRICE** | Hypothesis: **$29** one-time founding (below eventual annual/one-time test) |
| **PAYMENT STRUCTURE** | One-time founding-user access |
| **RISK REDUCTION** | 14-day refund if Cove Take not reachable; no auto-renew |
| **WHY IT IS DIFFERENT** | Not another allowance app—adventure + felt consequence; limited founding cohort for learning, not fake scarcity theater |

**Deploy phase:** 1 (first)
