# User Research Recruitment

**Agent role:** find representative people who can test Capital.  
**Starts from:** `docs/customer-discovery/` segment hypotheses (S1 Families, S2 Homeschool = P0).  
**Hard rules:**

1. **Do not automatically contact anyone.** Outreach drafts require human send.
2. **Do not collect unnecessary sensitive personal data** (see `SCREENER.md`).
3. **Small iterative cohorts** — never one giant study.
4. After every completed cohort: **STOP → analyze → decide product change? → recommend next cohort.**  
   Do **not** recruit the next cohort until findings are reviewed (`cohorts/STOP_GATE.md`).
