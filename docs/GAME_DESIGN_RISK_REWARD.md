# Capital risk / reward

Every major action should expose a readable trade:

| Lens | Question |
|------|----------|
| **Reward** | What do you stand to gain? |
| **Loss** | What are you exposed to? |
| **Uncertainty** | What isn’t guaranteed? |
| **Information** | What did you know before acting? |
| **Horizon** | When does it land? |
| **Recovery** | Can you respond without soft-resetting the past? |
| **Counterplay** | What tools or choices blunt the hit? |

**Rules**

1. Higher potential return should need meaningful exposure (not free wins).
2. No arbitrary punishment — dice may surprise, but the *choice* after the land creates the lesson.
3. Losses should open a new decision whenever possible (not only delete progress).
4. Recovery preserves consequences (scars stay) while restoring agency (pay down, rebuild cashflow, walk away).

Freeze: Harbor · Cove → Paycheck → Credit. Catalog: [risk-reward-audit.md](./risk-reward-audit.md).

## Spine relationships (shipped)

### Takes → ledger residue (not plaque-only)

Spend / glitter / haste scars write a **named liability** on the Voyager Ledger. Saver / wait / protect branches skip that exposure. Same quest item either way — the fork is monthly weight, not a deleted ending.

| Scar | Liability | Recovery Soft Beat |
|------|-----------|-------------------|
| Cove treat-before-jar | Treat Habit (−$/mo) | Lid Lookout — paydown |
| Paycheck glitter-ate-umbrella | Glitter Drip (−$/mo) | Umbrella Loft — paydown |
| Credit haste-fed-spiral | Haste Interest (−$/mo) | Score Battlement — paydown |

Plaques remain. Paydown removes the holding; Harbor still remembers the Take.

### Liability spaces → borrow / buyout / walk

Landing a Debt Trap is not silent `addHolding`. Same UI family as deals:

- **Borrow** — pouch coins now, accept −$/mo (higher near-term return, lasting exposure)
- **Buyout** — pay a lump sum, refuse the monthly trap
- **Walk** — one-time bill, no permanent holding

### Storm prices → cost, not subsidy

Weak cashflow / haste fog **raises** Harbor shop prices. Boom can still mark up when flush. Fog is interest weather — not a bargain bin.

### Island Bank → interest needs assets

Bank spaces pay only when the ledger holds income assets. Compounding requires something at risk.

### Soft Beat recovery → agency without erasure

Organ lookouts can offer a **paydown** when a matching Take liability exists. Decline and leave — scar and fog remain until cashflow or a later paydown.

## Still intentional soft / side

| System | Why it stays soft |
|--------|-------------------|
| Soft Beat with no liability | Aspiration hush — look / leave |
| Party lucky / free capsule | Side tomfoolery, not Freedom path |
| Mastery retry | Knowledge gate — dignity on fail (no coin slap) |
| Ritual +5 | Retention drip, never buys progress |

## Design checklist for new risk beats

- [ ] Does the high-reward branch expose a holding, bill, or access cost?
- [ ] If dice surprise, is there an informed fork after the land?
- [ ] Does the loss create a verb (pay, walk, rebuild) instead of only “try again”?
- [ ] Can the player recover without wiping the scar / plaque?
- [ ] Is counterplay a real tool (capsule, deal, Soft Beat paydown) — not a hidden reset?
