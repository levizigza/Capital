# First learning experiments (cheapest 3)

**Goal:** Meaningful learning (problem interviews + activation signals), not growth vanity.  
**Scale:** Forbidden until `SCALE_GATE.md` passes per channel.

---

## Why these three

| # | Channel | Class | Why cheapest for learning |
|---|---------|-------|---------------------------|
| 1 | **Mod-approved Reddit research posts** (r/Parenting / r/AskParents / r/daddit) | MANUAL_EARLY | $0 media; hours only; high S1 concentration; fast screener traffic |
| 2 | **Library / CU family program partnership ask** (1–2 local) | PARTNERSHIP | $0–small printing; public contacts; high-trust S1; seasonal but concrete |
| 3 | **Homeschool FB group research post** (1 secular + 1 general, admin OK) **or** GHC research pass | MANUAL_EARLY / PARTNERSHIP | $0–ticket; densest S2 intent; tests whether homeschool outranks S1 |

**Explicitly not first:** TikTok ads, Google ads, YouTube ads, large expo booths, influencer retainers.

---

## Experiment A — Reddit problem + optional playtest

| Field | Plan |
|-------|------|
| **ICP** | S1 |
| **Hypothesis** | Allowance/money threads contain parents with non-rail teaching pain who will book a 40-min interview |
| **Manual test** | 1 research post per sub (mod rules); link to screener; no product pitch in title |
| **Budget** | $0 media + $25–40 incentive × ≤4 completes |
| **Duration** | 14 days |
| **Success (learning)** | ≥8 screener passes **or** ≥4 interviews filed in customer evidence DB |
| **Activation learning (optional arm)** | ≥2 complete UT cold-signature activation after interview |
| **Kill / pivot** | &lt;3 screener passes in 14 days → change copy or sub; do not “boost” with ads |
| **Scale?** | **No** until arrive→activate→retain→WTP |

## Experiment B — Library or CU family program

| Field | Plan |
|-------|------|
| **ICP** | S1 |
| **Hypothesis** | Parents already attending money/story programs will join research and try Capital co-play |
| **Manual test** | Human email published library children’s contact **or** CU youth-ed contact; offer 1 evening remote research slots + optional on-site demo night |
| **Budget** | $0–50 print flyer; incentives as above |
| **Duration** | 21 days (includes scheduling lag) |
| **Success (learning)** | ≥1 org agrees to share invite **and** ≥3 parent conversations |
| **Kill / pivot** | 5 org nos with same objection → document barrier; try alternate city—not paid awareness |
| **Scale?** | **No** until gates pass |

## Experiment C — Homeschool attention (FB admin post ± GHC)

| Field | Plan |
|-------|------|
| **ICP** | S2 |
| **Hypothesis** | Curriculum-shopping parents have higher urgency/WTP language than general S1 |
| **Manual test** | Admin-approved research post in 2 groups; optional cheap research attendee pass at GHC if calendar aligns (not full booth) |
| **Budget** | $0 posts; GHC pass only if &lt; cost of a week of ads and timeboxed |
| **Duration** | 14–28 days |
| **Success (learning)** | ≥3 homeschool interviews with filled `money_currently_spent` + `desired_outcome` |
| **Compare** | Side-by-side with Experiment A on urgency/WTP language (interview evidence)—do not crown ICP from n=1 |
| **Scale?** | **No** until gates pass |
