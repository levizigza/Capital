# Talk — problem discovery (S1)

Use only with **founder-approved** contacts. Do not send autonomously.

## Goal

Understand money-learning pain for families with kids ~6–11 **before** pitching Capital.

## Script (20–30 min)

1. Context: how does money come up at home?  
2. Last time it went poorly — what happened?  
3. What have you tried (apps, books, allowance systems)?  
4. What would “working” look like in 30 days?  
5. Willingness-to-pay signal (open): “If something solved that, what would you expect to pay?” — do **not** invent a price promise.  
6. Optional: ask if they’d try a 20-minute playtest later (TEST step).

## Record

- Add/update person in `docs/revenue-intelligence/data/ledger.json` with `INTERVIEWED`  
- Capture objection/pain candidates for LEARN (no fabrication)  
- Run `npm run first-revenue:dashboard`
