# Lean path now (not the full AI company)

**Do not wait until fifteen corporate agents exist before trying to earn a dollar.**

First milestone for Capital:

> Get **one stranger** who matches our intended customer to **use Capital**, experience value, **willingly pay through Stripe**, and **come back**.

Once that is reproducible, the broader AI-company architecture has something worth scaling.

## Build / use this stack first

| Order | Capability | Job in the loop |
|------:|------------|-----------------|
| 1 | **Lead Finder** | Name ~20 plausible S1 people (founder-approved sources only) |
| 2 | **User Recruiter** | Get a handful into interviews / sessions (no spam) |
| 3 | **User Testing** | Watch ~5 target users actually use Capital |
| 4 | **Sales Copilot** | Help craft one honest offer after friction is known |
| 5 | **Stripe Quick-Revenue** | **Payment Link** (test → live with founder approval) |

Defer multi-agent “company OS” automation until this loop produces retained payers.

## Real operating loop

```
Find ~20 plausible people
  → interview a handful
  → watch ~5 target users use Capital
  → fix the largest friction
  → make an offer
  → send a Stripe Payment Link
  → see whether someone pays
  → see whether they return
  → repeat
```

This is closer to YC’s “first customers by any means necessary” than another quarter automating a hypothetical corporation.

## Success metric

**Not:** leads, traffic, followers, free accounts, or “agents shipped.”  
**Yes:** a matching stranger who pays and remains.
