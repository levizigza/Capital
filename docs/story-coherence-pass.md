# Story coherence pass — one myth, continuous playthrough

**Job:** Harbor → Cove → Paycheck → Credit reads as one story a kid can retell without the UI explaining a second cosmos.  
**Freeze:** Main quest strip stays four-wide. Era side shores stay quiet discovery, never the next verb.

## Eight kid beats (source of truth)

1. **Harbor** — Home. Memory keeps. Talk to Piggy when you choose.  
2. **Carpet** — Board a painting. Cove first.  
3. **Cove Take** — Jar or treat; you cannot put it back. The Coin holds.  
4. **Harbor felt that** — Plinth → share → Piggy names Coin holds → next painting is **Paycheck** (era shores optional).  
5. **Paycheck Take** — Umbrella or glitter. The Clock shelters.  
6. **Harbor again** — Clock plaque; next painting is **Credit**.  
7. **Credit Take** — Wait or haste. The Spiral withstands.  
8. **Day-2 / Memory** — Plinth still names yesterday’s organ with the same kid sentence.

## Laws

- Organ kid verbs only: holds · shelters · withstands · keeps. Never “Clock Take” / “Coin Take.”  
- Spine shore HUD = organ + place + next verb — not genre city names.  
- Post-homecoming next painting is organ-aware (Cove→Paycheck, Paycheck→Credit).  
- Side shores never steal Piggy’s primary tip.  
- Ashore teach matches Harbor first-meet story (Talk → Carpet → Cove).  
- No player-facing “Main course (n/m).”
