# FTUE / observational playtest templates

Reusable research artifacts for:

- [`docs/design/OBSERVATIONAL_PLAYTEST.md`](../../design/OBSERVATIONAL_PLAYTEST.md) — structured process  
- [`FTUE_USABILITY_PROTOCOL.md`](../FTUE_USABILITY_PROTOCOL.md) — FTUE silence + intervention detail  

Copy a template into a working notes folder (or a private cohort doc). **Do not commit participant PII.**

| File | When |
|------|------|
| `TEMPLATE_PARTICIPANT_BRIEF.md` | Start of every session |
| `TEMPLATE_OBSERVER_SCRIPT.md` | Observer pocket card |
| `TEMPLATE_OBSERVATION_CHECKLIST.md` | Record lenses tick-list |
| `TEMPLATE_SESSION_LOG.md` | During every session |
| `TEMPLATE_FINDING.md` | One card: OBSERVATION · INTERPRETATION · HYPOTHESIS · RECOMMENDATION |
| `TEMPLATE_COHORT_SUMMARY.md` | After each 3–5 person cohort |
| `TEMPLATE_RETEST.md` | After a fix lands |

**Loop:** small cohort → findings → fix repeated majors/blockers → retest.

Optional local folder (gitignored or anonymized only): `cohorts/YYYY-MM-DD-build/`
