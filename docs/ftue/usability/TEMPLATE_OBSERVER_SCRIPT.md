# Observer script — Capital FTUE

**Law:** Do not help unless an exception below fires. Record every help ask.

---

## Before session

- [ ] Fresh or profiled save per recruit plan (`?fresh=1` for New)  
- [ ] Note `ftue_version` / build / `?exp=` variant  
- [ ] Timer ready; session log open  
- [ ] Second observer optional (one silent note-taker)

## Opening (read aloud)

> Thanks for helping. We’ll watch you play Capital’s opening. Please think out loud if you can. If you get stuck, try what you’d try in a real game — we won’t give hints during play unless something is broken.

## When they ask for help (default)

Say **only**:

> Keep going with what you’d try in a real game. I’ll note the question.

Then write the ask under **Asks for help** in the session log.

## Think-aloud nudge (max 2× per session)

If silent >60s and idle:

> What are you trying right now?

Do **not** suggest verbs, places, or choices.

## Allowed interventions (log as INTERVENTION)

| Code | When | What you may do |
|------|------|-----------------|
| I-SOFTLOCK | >90s no recoverable action / stuck UI | Unstick UI or restart segment; mark task contaminated |
| I-CRASH | Crash, blank, infinite load | Reload / restore; mark contaminated |
| I-A11Y | Cannot perceive required signal | Open Settings only; do not solve the puzzle |
| I-STOP | Distress | End session; thank them |

Script for softlock:

> Something looks stuck on our side — I’ll reset this bit. That’s on the game, not you.

## Forbidden (always)

- Naming the interact key as the solution to a hesitation  
- Explaining jar vs treat “correctness”  
- Pointing at Piggy, Carpet, or Kira  
- Celebrating or correcting their Take during play  
- Answering “what should I do?” with content

## Closing play → interview

> That’s enough play for today. I’m going to ask what you noticed — still no right answers.
