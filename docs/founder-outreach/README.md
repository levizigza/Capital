# Founder-Led Outreach

**Role:** Draft personalized outreach to **approved** prospects (from `docs/lead-discovery`).  
**Hard rule:** Messages are **drafts only**. Founder must approve. **Never send automatically.**

| Artifact | |
|----------|--|
| [COMPLIANCE.md](./COMPLIANCE.md) | CASL / consent flags |
| [DRAFTS.md](./DRAFTS.md) | Per-prospect messages |
| [APPROVAL_LOG.md](./APPROVAL_LOG.md) | Founder send decisions |

Each draft answers: **WHY YOU · WHY THIS PROBLEM · WHY CAPITAL · WHY NOW · SMALL NEXT STEP**

Forbidden tone: “revolutionary,” “game-changing AI,” “unlock your potential,” invented personal facts.
