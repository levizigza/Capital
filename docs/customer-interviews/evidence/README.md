# Customer Evidence database

De-identified interview evidence. **Update after every interview.**

## Files

| File | Role |
|------|------|
| `EVIDENCE_INDEX.md` | Human-readable index of all interviews |
| `records.jsonl` | One JSON object per interview (machine) |
| `I-*.md` | Full notes from template |
| `ICP_PROPOSALS.md` | Only when recurrence gates met |

## Privacy

No child legal names, school IDs, exact addresses, SSNs, or precise income.
