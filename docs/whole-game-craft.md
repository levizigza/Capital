## Patterns from all-time great games

| Pattern | Games | Capital law |
|---------|-------|-------------|
| One fantasy, many verbs | Zelda · Portal · Hades | Voyager among living money — every surface asks that |
| Multiplicative, not additive | BotW chemistry | Organs · Take · Plinth · Piggy share one vocabulary |
| Teach in the world | HL2 · Portal | Ashore Talk → Carpet → Cove (no checklist gates) |
| Return changed | Outer Wilds · Celeste | Harbor *proves* the Take (spectacle → share → day-2) |
| Readable silhouette | Nintendo craft · Astro | Structures + mascots read without HUD essays |
| Juice on the verb | Celeste · Mario | Take mark · Plinth · share · Piggy homecoming sting |

## Stack honesty (Blender / Unity / public APIs)

Capital ships as **React + R3F + Vite** in the browser.

| Suggestion | How we use it |
|------------|----------------|
| Blender repo | Craft inspiration (silhouette, lighting, character appeal) — not a native Blender pipeline on the spine |
| Unity Technologies | Same — pattern names / NPC blackboard ideas only; live world is procedural R3F |
| public-apis | Optional flavor later; core loop stays offline-first for kids (no network required to feel Harbor) |

Deepen procedural organ world + silhouette craft before importing heavy asset pipelines.
