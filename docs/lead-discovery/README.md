# Lead Discovery

**Mission:** Identify people/orgs likely to have the problem Capital addresses.  
**Approved ICP start:** fit-gated discovery pool — **S1 Families (6–11)** and **S2 Homeschool** primary; **S3 Youth/CU education** and **S4 Teachers** as channel/B2B adjacents (`docs/customer-discovery` hypotheses).

## Hard rules

| Forbidden | Required |
|-----------|----------|
| Mass-messaging | Legitimate public sources only |
| Invented email addresses | Published org contacts / contact forms only |
| Inferring sensitive personal traits | Problem signals from public programs/news |
| Scraping private groups/directories | Source URL + date noted |
| Automatic outreach | Human reviews + interview agent scripts |

**Quality bar:** Prefer **~20 strong leads** over thousands of weak ones. Output = **qualified only** (score ≥ 60 unless noted).

| Artifact | |
|----------|--|
| [SCORING.md](./SCORING.md) | 0–100 lead score dimensions |
| [QUALIFIED_LEADS.md](./QUALIFIED_LEADS.md) | Ranked leads with evidence |
| [OUTREACH_POLICY.md](./OUTREACH_POLICY.md) | Human-only, no auto-contact |
