# Astro craft → Capital

How Team Asobi’s Playroom / Astro Bot hub craft and [Impeccable](https://github.com/pbakaus/impeccable) distill/quieter rules map onto Capital Islands.

## Pillars (Asobi → Capital)

| Asobi | Capital translation |
|-------|---------------------|
| Magical / Playful / Inclusive / Innovative | Money feels alive; family-safe; portals teach by looking right |
| Gameplay idea → world | Save → Coin Jar; earn → Payroll Tower; borrow → Interest Keep; home ledger → Ledger Bank |
| CPU Plaza = few clear gates | Harbor = fountain + bank + carpet gate + 2–3 pavilions — not a ring of clone shops |
| Portal previews destination | Gate silhouette / palette / material matches the world you enter |
| Toy culture | Interactive props that reward poking; decoration without play is noise |
| Secrets under quiet surface | Depth exists; spawn vista stays calm |

## Harbor squint test

From spawn, a cold player must name **three** places without HUD help:

1. **Fountain** — plaza center  
2. **Ledger Bank** — money machine hero  
3. **Money Carpet Gate** — leave home / archipelago  

Secondary places use **signposts or boards**, never identical yellow-roof shops.

## Wayfinding (existing W-rules)

See [island-design-process.md](./island-design-process.md): **W2 one hero per area**, W1 rule of three, W11 eye trail. Harbor craft must obey these.

## Impeccable reflexes for Islands

- **Distill:** fewer landmarks, more contrast between them  
- **Quieter:** one primary CTA; buddy tip one line; map diegetic at the carpet gate  
- **Spatial rhythm:** tight clusters + generous negative space (no uniform prop rings)  
- **Experience mode** on the plaza: world leads; chrome recedes
