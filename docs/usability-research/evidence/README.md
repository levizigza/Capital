# Evidence stubs

De-identified only. No names, emails, faces descriptions that identify kids.

## File naming

`E-001.md`, `E-002.md`, …

## Stub format

```markdown
# E-001

- session_id:
- participant_id: P-A1-01
- test_id: UT-03
- t_approx: 00:18:40
- recording_id: (private) / none
- outcome_at_time: success | fail | partial | n/a

## Observable behavior

…

## Verbatim (optional, short)

> …

## Linked findings

- F-XXX
```

## Privacy

If evidence cannot be anonymized, keep it **outside** the repo and leave only `recording_id` + hash of notes here.
