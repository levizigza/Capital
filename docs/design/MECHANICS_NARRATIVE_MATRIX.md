# Capital — Mechanics ↔ Narrative Matrix

**Status:** Narrative audit against shipped play + canon  
**Law:** Prefer **DECISION → CONSEQUENCE → CHARACTER/WORLD RESPONSE → NEW DECISION**.  
**Avoid:** GAMEPLAY → STOP → STORY → STOP → GAMEPLAY (cutscenes that don’t change the next verb; lore that no mechanic can prove).  
**Companions:** `story-bible.md` · `CAPITAL_DESIGN_BIBLE.md` · `DECISION_AUDIT.md` · `CAUSAL_TIME_SYSTEM.md` · `SYSTEM_INTERACTION_MATRIX.md` · `CAPITAL_DESIGN_CONSTITUTION.md`

**Story engines (canon):** Harmon Story Circle + Hero’s Journey — but **beats must ride mechanics**, not replace them.

---

## 1. Preferred loop (narrative = play)

```
DECISION          (Take · Deal · Wait · Talk fork · Pay Day claim)
      ↓
CONSEQUENCE       (ledger · scar · irreversible · pouch)
      ↓
CHARACTER/WORLD   (Piggy · locals · weather · Plinth · Debt Collector)
      ↓
NEW DECISION      (next Opportunity · next organ door · repair Talk · sail)
```

If a narrative beat has no arrow into a new decision, it is a **STOP** — demote to flavor or wire a mechanic.

If a mechanic never produces a character/world response, it is a **mute grind** — add Memory/Piggy/weather or cut.

## 7. Anti-pattern checklist

- [ ] Does this cutscene change a save field the next decision reads?  
- [ ] Does this mechanic produce a line Piggy/Plinth/weather can say?  
- [ ] If I remove the prose, does the system still tell a money story?  
- [ ] If I remove the system, is the prose a lying brochure?  

Any “no” → STOP coupling; fix before ship.

## 8. Priority opportunities (narrative craft, no map widen)

1. **Paycheck Take** — give Clock fork a real CONSEQUENCE (CF/obligation) so identity isn’t empty.  
2. **Deals ↔ Piggy/Bag** — world responds to Accept/Wait (relationship + opportunity).  
3. **Credit risk** — weather/Bag ESTIMATED preview → conflict/identity without quiz-as-story.  
4. **Series leads** — when scars exist, lines must BECAUSE-retell (or stay silent).  
5. **Demote quiz** as meaning-bearer; keep as optional proof, not chapter soul.  

Align with Living Cashflow Commit + Decision Preview when prototyping.

---

## 9. Success criteria

- A cold player retells *a choice they made* and *who answered*, not a cutscene they watched.  
- Every spine organ has at least one DECISION→…→NEW DECISION loop with Memory or CF.  
- No major Harmon beat is carried only by text.
