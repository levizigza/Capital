# Capital — Progression Taxonomy

**Status:** Design law for what “progress” means  
**Unlock test (mandatory):** *What new decision becomes possible?*  
If the only effect is **numerical inflation** (bigger number, same choices) → remove, demote to expression, or redesign.  
**Companions:** `CAPITAL_DESIGN_BIBLE.md` (progression philosophy) · `DECISION_AUDIT.md` · `MECHANICS_NARRATIVE_MATRIX.md` · `CONCEPT_MASTERY_PEDAGOGY.md` · `PLAYER_HISTORY_SYSTEM.md` · `UI_LAYER_AUDIT.md`

**Anti-pattern:** Character-creation archetype menus (“I am a Saver”). Identity emerges from **decisions** Harbor can name.

---

## 1. Nine progression tracks

Keep these **separate in design thinking** even when one beat touches several. Do not collapse everything into XP.

| Track | Meaning in Capital | Player feels it when… | Advances by… |
|-------|--------------------|----------------------|--------------|
| **PLAYER KNOWLEDGE** | Concepts understood (rules, organs, CF) | They can retell because-lines; transfer succeeds | Guided decision → consequence → independent transfer (`CONCEPT_MASTERY_PEDAGOGY`) |
| **PLAYER SKILL** | Execution under pressure (sort, timing, board routing) | Pads clear; fewer dignity retries | Practice, assist decay, difficulty adaptation |
| **CAPABILITY** | Verbs the body can do (Walk, Talk, Board, Enter Structure, Preview, Why?) | New verb appears in a place | Ashore/Harbor teach; Soft Beat peek; Structure enter |
| **RESOURCES** | Stocks that fuel decisions (pouch, CF, holdings, streak) | Pay Day / deal / weather change | Earn, deals, Takes, Pay Days — **not** XP |
| **ACCESS** | Places and systems reachable | Map pin opens; Pavilion door; side shores | Cove Change, Freedom, (Credit gate — revisit quiz) |
| **REPUTATION** | How Harbor/household speaks of you | Day-2 locals, Piggy tone, Witness stamps | Scars, share, Family Room — local only |
| **WORLD STATE** | Living world configuration | Sky band, shop prices, quiet homecoming, Soft Beat arm | CF, scars, ritual timing, cinema gates |
| **COLLECTION** | Optional sets (digression shelf, capsules owned, marks) | Shelf fills; inventory toys | Side play — **never gates spine** |
| **IDENTITY** | Who you became (plaques, organ story, Freedom escaped) | Plinth / Fortune Thread / cast look as costume only | Irreversible Takes + lasting CF residue |

### Track hygiene

| Do | Don’t |
|----|-------|
| Let Knowledge unlock quieter guidance (SILENT more often) | Equate quiz clears with Knowledge MASTERED alone |
| Let Resources change Opportunity rationality | Treat wealth rank as Identity |
| Let Access open new forks | Gate Access on Collection completion |
| Let Identity emerge from Takes | Offer “pick your money personality” at cast select |

## 3. Numerical inflation — remove or reconsider

| Candidate | Why it fails the unlock test | Disposition |
|-----------|------------------------------|-------------|
| XP / level ups | Same verbs, bigger number | **Remove** from player progress story |
| Wealth rank (Flat broke → Tycoon) | Inflates Cash display narrative | **Remove** from HUD; Cash integer enough |
| Carpet tiers beyond Fortune flyer | Same sail decisions | **Expression shop only** |
| Party “seals” / Board Stars as Freedom cousins | Confuses Access/Identity | **Rename Board Star**; never progress spine |
| Stacking identical-ROI deals as “levels” | More +$/mo without new tradeoff shape | **Differentiate** deal risks (Living Cashflow Commit) |
| Mastery clears as score chasing | Access via quiz inflation | **Replace/reduce** with transfer + CF proof |
| Ritual streak days | Login theater | **Demote** |
| skillStats grinding | Hollow RPG | **Don’t surface**; don’t gate |

**Allowed number growth:** pouch and CF when they **change which Wait/Accept/Take is rational** — that is Resources enabling decisions, not vanity inflation.

## 4. Nesting horizons (decision-bearing)

| Horizon | Progress that matters | Track mix |
|---------|----------------------|-----------|
| Short | Take → Soft Beat → day-2 | Identity, World, Reputation |
| Medium | Deals → CF → Freedom chase | Resources, Knowledge, Access |
| Long | Freedom → Credit Ordeal | Access, Identity, Knowledge (transfer) |

Side Collection and expression run **parallel**, never blocking long horizon.

## 5. Emergent behavioral archetypes

**Not chosen at cast select.** Cast look is costume. Archetypes are **readouts** Harbor/Piggy/Thread may name after evidence accumulates — soft myth, never a locked class.

### 5.1 Emergence rules

An archetype tag may surface (Piggy line, Chronicle footnote, Witness flavor) when:

1. ≥1 irreversible or lasting CF pattern matches, **and**  
2. Player is past first Harbor homecoming, **and**  
3. Tag is descriptive, not a buff, **and**  
4. Player can still break the pattern (except spent irreversible plaques — those stay “you once chose…”).

No exclusive singleton: someone can be **Holder** and later **Storm-walker**.

### 5.2 Archetype seeds (from decisions)

| Emergent tag | Evidence (examples) | New decisions it colors (not gates) | Not from |
|--------------|---------------------|-------------------------------------|----------|
| **Holder** | Jar Take; asset deals; Wait when buffer thin | Favors Holds language; Piggy warm on booth | Cast “saver” checkbox |
| **Spender-of-now** | Treat Take; glitter; impulse digressions | Owes/Risk literacy; recovery arcs | “I’m fun” menu |
| **Patient spiral** | Credit wait; Soft Beat before Take | Risk ESTIMATED previews | Quiz score |
| **Haste-scarred** | Credit borrow; storm while CF&lt;20 | Weather-aware Commits | Random night |
| **Powder-keeper** | Repeated Wait; high liquidity | Deal timing skill | Coward label |
| **Escaped** | Freedom Seal | Pavilion expression; Credit door | Instant flyer cheat |
| **Witnessed** | Family stamps on scars | Household myth lines | Online rank |
| **Shelf-curious** | Digression pairs filled | Side ACCESS only | Completionist force |

Stance counters (`saver`/`spender`/`risk`) may **feed evidence silently** — never as character-creation picks or HUD badges.

### 5.3 Anti-archetypes (forbidden)

| Forbidden | Why |
|-----------|-----|
| Cast select “Choose your money class” | Identity before play |
| Buffs tied to Holder (+10% CF) | Pay-to-identity / inflation |
| Permanent class lock after one Take | Denies recovery story |
| Archetype quiz as MASTERED | Click-through mastery |

## 7. Design checklist (every new unlock)

- [ ] Primary track named (one; secondary OK)  
- [ ] **New decision** written in one sentence  
- [ ] Not pure numerical inflation  
- [ ] If Identity: emerges from play evidence, not menu  
- [ ] If Collection: cannot gate Credit / Freedom  
- [ ] If Access: names what fork/place opens  
- [ ] UI layer placement (`UI_LAYER_AUDIT`)  

---

## 8. Priority reconsiderations

1. **Credit gate** — Access should follow spine/CF/transfer proof more than quiz inflation.  
2. **Carpet beyond Fortune flyer** — Collection/expression only.  
3. **XP / wealth rank / skill HUD** — remove from progress fantasy.  
4. **Emergent tags** — wire Piggy/Thread readouts after jar/treat/Freedom/haste (no creation menu).  
5. **Deal differentiation** — Resources growth must create new Wait/Accept tensions.  

---

## 9. Success criteria

- Designers can place any unlock in exactly one primary track.  
- Players feel “I can decide new things,” not “my number went up.”  
- Cold retell names Holder/Spender/Escaped from **choices**, not from a title screen class.  
- Collection completionists never unlock Credit solely by shelf-filling.
