# Puzzle-explorable craft lens

**Source:** [Tom Hermans — How to make a good puzzle](https://auroriax.com/puzzle-explorable/)  
**Job:** Apply Presentation · Elegancy · Aspiration to Capital’s signature loop and Takes — without widening the map.

## Presentation

A beat should **explain itself**. Jar reads as hold; tower as payday pressure; keep as interest gravity.  
**Show all puzzle pieces** when the player must decide — both forks of a Take, all four spine paintings, Soft Beat vs arcade pads labeled honestly.

## Elegancy

Use the **smallest solvable setup**. Strip red herrings (future-island foreshadow on Cove, Soft Beat sold as the Take site, checklist chrome).  
Player time goes to thinking about the Take — not decoding wrong vocabulary.

## Aspiration

Each painting teaches a **new** facet of living money (Coin holds → Clock shelters → Spiral withstands). Soft Beat peeks teach **entering the machine**, not a re-run of the Take line. Harbor return teaches Memory keeps.

## Capital mapping

| Surface | Hermans move |
|---------|----------------|
| Ashore Paintings | Place + real Take site (not Soft Beat crown) |
| Cove / Paycheck / Credit forks | Choice text = plaque vocabulary |
| Soft Beat | Climb + new vista; not “Harbor felt that” again |
| Structure entryHint | Arcade pads open worlds; Soft Beat pad = quiet peek |
| Spectacle / share | One job: Harbor proves Memory / newly true painting |

## Freeze

Main-quest strip stays Harbor · Cove → Paycheck → Credit. No fake multiplayer. No foreign merges.
