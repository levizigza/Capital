# Founder Sales Copilot

**Job:** Help the founder prepare for and capture sales conversations.  
**Not the job:** Replace the founder on early customer discovery calls. Interview agent + discovery still own problem research.

| Hard rule | |
|-----------|--|
| No invented features | Only ship what Harbor/Cove/spine actually does |
| No unauthorized discounts | Founder-approved list only |
| No official pricing changes | Pillars paid model stays **hypothesis** until founder sets SKUs |
| No undeliverable promises | No fake multiplayer, no bank rails, no “class codes ready” unless shipped |
| READY TO BUY | Use simplest **approved** payment path; do not wait on unfinished billing automation |

| Artifact | |
|----------|--|
| [PRE_CALL.md](./PRE_CALL.md) | Prep checklist |
| [POST_CALL.md](./POST_CALL.md) | Capture + classification |
| [OBJECTIONS.md](./OBJECTIONS.md) | Likely objections (honest answers) |
| [PRICING_HYPOTHESIS.md](./PRICING_HYPOTHESIS.md) | Non-canonical pricing notes |
| [PAYMENT.md](./PAYMENT.md) | Approved mechanisms + Stripe Payment Link request |
| [calls/](./calls/) | Per-call notes |
| [templates/](./templates/) | Blank prep/capture forms |
