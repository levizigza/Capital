# Pre-call prep

Fill before every founder sales or late-stage pilot conversation.  
If the meeting is **pure discovery**, use `docs/customer-interviews` instead and skip pricing.

## Template

```markdown
# Pre-call — [prospect] — [date]

## customer context
- org / person:
- segment (S1–S8 / other):
- source (lead id / channel):
- public facts we actually know:
- prior touch (outreach draft id / interview id):

## likely problem
- one sentence (from their world, not our pitch):

## evidence
- links / quotes / lead score notes:
- what we must NOT claim to know:

## questions (behavior-first; max 8)
1.
2.
…

## possible objections
- (see OBJECTIONS.md — pick 3 likely)

## pricing hypothesis
- SKU under discussion: base license / pilot / other
- amount: **FOUNDER-SET ONLY** (see PRICING_HYPOTHESIS.md — do not invent)
- discount: none unless on approved list
- what is included in product today (honest):
  - Harbor → Cove signature loop (Take → Plinth → share)
  - Paycheck / Credit on spine when unlocked
  - NOT: debit rails, cloud multiplayer, shipped class-code LMS

## call goal
- [ ] learn only
- [ ] qualify
- [ ] propose pilot
- [ ] close if READY TO BUY
```

Save as `calls/PRE-YYYYMMDD-[slug].md`.
