# Objections (honest responses)

Founder may adapt wording. **Never invent roadmap dates or features.**

| Objection | Honest stance |
|-----------|----------------|
| “We need a real debit card / allowance rails.” | Capital is practice-in-fiction + adventure, not banking. If rails are must-have, we are **NOT_ICP** for that buyer—or RESEARCH only. |
| “Is there multiplayer / family accounts in the cloud?” | Family Room is **local device** share by design. Do not promise fake multiplayer. |
| “Do you have class codes / roster / standards map?” | Classroom tooling is **later** in pillars; today is family/adventure spine. Teachers → RESEARCH or PARTNERSHIP learning, not fake LMS. |
| “Can you guarantee learning outcomes / test scores?” | We can speak to design intent (irreversible choice, felt consequence). No fabricated efficacy stats. |
| “Too kid / too game for adults.” | Solo-adult segment is weak product fit on iconic path—classify accordingly. |
| “Price?” | Only state **founder-approved** hypothesis or SKU. If unset: “We’re finalizing license options; for a pilot we can use a simple payment link once terms are clear.” Do not invent $. |
| “Discount?” | Only if on **approved discount list**; otherwise no. |
| “Send a deck / leave-behind first.” | Prefer play link to Harbor cold path over vapor slides. |
| “COPPA / privacy?” | Be accurate: parent data access gated; no overclaim. Offer security docs if they exist; don’t invent certifications. |
| “We’ll build it ourselves.” | Acknowledge; ask what they’ve tried; don’t argue. |

## Promises never to make

- Pay-to-win currency or paid skips of learning  
- Instant district-wide rollout tooling that isn’t shipped  
- Merging unrelated projects into Capital  
- Map width beyond Cove → Paycheck → Credit as the sales wedge while iconic freeze holds
