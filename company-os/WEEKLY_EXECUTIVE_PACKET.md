# Weekly Executive Packet (pointer)

One weekly founder digest: what happened → truths → economics → retention →
sales → experiments → agents → failures/risks/opportunities → decisions →
automatic actions.

Founder recommendations always include evidence, upside, cost, confidence,
reversibility, worst case, and alternative.
